Fichas provisionales

Registra negocios y lugares de ocio como propuestas privadas. Solo pasan a la web pública cuando las apruebas.

Importar lote de fichas provisionales

Pega un array JSON de negocios o lugares de ocio. Se guardarán como propuestas privadas pendientes; nunca se publican automáticamente. Máximo 100 fichas por lote. Campos: n (nombre), c (categoría), t (negocio/ocio), a (dirección), p (teléfono), e (correo), w (web), h (horario), s (destacado), d (descripción), source_name, source_url, source_checked_at, notes.
